## 📌 Production Architecture & Current Work

**What I Specialize In:**

- **Microservice Resiliency & Event Backbones:** Implementing reliable messaging via RabbitMQ (exchanges, routing, dead-letter queues, outbox pattern) across Order, Inventory, Location, User, and Notification services.
- **API Gateway & Edge Security:** Building Spring Cloud Gateway filters for JWT verification, distributed Redis token denylisting, IP & identity rate limiting, and internal secret propagation.
- **Enterprise CI/CD & Failover Pipelines:** Architected high-availability dual-CI pipelines combining Jenkins Multibranch Pipelines (`@Library('quickman-ci')`) and automated GitHub Actions failovers with SonarQube quality gates and secret scans.
- **Full-Stack Portals & Mobile Apps:** Designing Next.js merchant/admin dashboards (POS, live kitchen display, stock management) and React Native mobile marketplace applications with real-time tracking.

**Production Engineering Highlights:**
- 🛡️ **Zero-Trust Security:** Hardened Actuator health endpoints, eliminated sensitive credential leaks, and enforced idempotent transactional APIs (`Idempotency-Key` contract enforcement).
- 📊 **Metric Instrumentation:** Introduced custom Micrometer telemetry to eliminate silent distributed failures during Redis degradation.
- 📐 **Contract Consistency:** Authored the comprehensive **"Backend Review — Nine Services"** audit, synchronizing cross-service role precedence and API schemas.
